# 🎓 StudyMate — AI-Powered Study Assistant

StudyMate is a modern desktop-based AI study assistant built to help students learn, practice, and explore concepts from one application.

It combines Artificial Intelligence with real-world APIs to provide an interactive learning experience.

---

## ✨ Features

### 🤖 AI Tutor
Ask study-related questions and get simple, student-friendly explanations using Google Gemini AI.

### 📝 AI Quiz Generator
Enter a topic and generate a 5-question multiple-choice quiz using Gemini AI.

### 🌤️ Weather
Search for any city and view:
- Temperature
- Feels-like temperature
- Humidity
- Wind speed

Powered by the Open-Meteo API.

### 📖 Dictionary
Search English words and get:
- Definitions
- Parts of speech
- Examples

Powered by Dictionary API.

### 📊 Study Dashboard
The dashboard displays:
- Study sessions
- Current streak
- Quiz statistics
- Study time
- Weekly progress
- Quick actions

### 🎨 Modern User Interface
Built with CustomTkinter and includes:
- Dark mode
- Light mode
- Sidebar navigation
- Rounded cards
- Clean layout
- Interactive buttons
